# 个人 Agent 示例

这是一个基于 Python 和 Flask 的最小可运行个人 agent 项目，带一个简单 Web 页面。

## 功能

- 聊天式交互
- 添加待办
- 查看待办
- 完成待办
- 记录个人笔记
- 输出今日摘要

## 启动方式

1. 安装依赖

```bash
pip install -r requirements.txt
```

2. 启动服务

```bash
python -m app.main
```

3. 打开浏览器

访问 [http://127.0.0.1:8000](http://127.0.0.1:8000)

## 示例指令

- `添加待办：整理项目计划`
- `记住：下周三下午和客户开会`
- `查看待办`
- `完成待办 1`
- `今日摘要`
